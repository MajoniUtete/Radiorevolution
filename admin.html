🖥️ BUTT Setup

Configure BUTT (Broadcast Using This Tool) to auto-notify listeners when you start streaming.

How BUTT ➡️ Notifications works:

1. Open BUTT → Settings → Events
2. Under "On Connect", set your script path:
notify-live.sh (see below)

3. Every time you hit Play in BUTT, the script fires a webhook to your server, which sends push notifications to all listeners automatically.
notify-live.sh
#!/bin/bash # BUTT on-connect webhook script # Place this file where BUTT can find it API_URL="https://your-api.radiorevolution.co.zw" HOST_KEY="your-secret-host-key" curl -s -X POST "$API_URL/broadcast/live" \ -H "Content-Type: application/json" \ -H "X-Host-Key: $HOST_KEY" \ -d '{"status":"live","host":"'$BUTT_STREAM_NAME'"}' \ > /dev/null 2>&1 exit 0
Make executable: chmod +x notify-live.sh
